# Team tasks before the final presentation

The code and tools for every item below are finished and tested. What's left needs **a person**: someone who listens to audio, reads Hindi, or makes a judgement. These can't be generated by the code without making the evaluation meaningless.

Total effort: roughly **6–8 person-hours**, and the tasks can run in parallel.

| # | Task | Who | Time | What it unlocks in the slides |
|---|---|---|---|---|
| 1 | NER gold annotation (2 annotators) | 2 people | ~2 h each | NER precision / recall / F1, inter-annotator κ |
| 2 | Adjudicate disagreements | same 2, together | ~45 min | Final gold set |
| 3 | Hindi reference transcripts (2 min × 5 recordings) | 1 Hindi reader | ~1.5 h | Hindi WER / CER |
| 4 | Kajal reference form | 1 person | ~30 min | Evaluation on 5 cases instead of 4 |
| 5 | GLiNER baseline on Kaggle | 1 person | ~30 min | Rules vs neural model comparison |
| 6 | Data-privacy decision | whole team | 10 min | Avoids an ethics deduction |
| 7 | Demo rehearsal + backup recording | presenter | ~30 min | Safe live demo |

When tasks 1–5 are done, run this and copy the new numbers into the slides:

```bash
python3 src/run_all_evaluations.py
```

## 1. NER gold annotation (two people, independently)

Rules: **don't look at the model's output or your teammate's file before you finish.** Copying predictions into the gold set would make the scores meaningless, and examiners know this.

1. Start the server: `python3 src/serve.py`, then open **http://127.0.0.1:8080/annotate.html**.
2. Click **Load template** and choose `outputs/annotations/<Case>_gold.json` (Kajal, Praveen, Priyanshi, Swarnima, Uday).
3. Type your annotator ID: the first person uses **`r1`**, the second **`r2`**.
4. Select text with the mouse → pick the **entity type** and **assertion** → **Add**. Follow the guidelines panel on the right of the page.
5. Click **Download my annotations**. Move the file into `outputs/annotations/`. It's named `<Case>_r1.json` or `<Case>_r2.json`.

Do all 5 transcripts, or at least 3 if time is short (say so in the slides).

## 2. Agreement and adjudication

```bash
python3 src/annotation_agreement.py
```

- This prints **inter-annotator agreement**, both pairwise F1 and Cohen's κ. Put this table in the slides: it shows your gold data is reliable.
- It also writes `<Case>_gold.json` containing the annotations you **agreed** on, plus a list of **disagreements**.
- Sit together, load each `<Case>_gold.json` in the annotation page, and resolve every disagreement with **Accept A / Accept B / Reject**. Download the file and replace the old one. When no disagreements are left, the status becomes `complete`.
- `python3 src/run_all_evaluations.py` then reports **NER P/R/F1**.

## 3. Hindi reference transcripts (WER/CER)

For each recording, listen to the **first 2 minutes** and type exactly what was said, in Devanagari. Keep English words as spoken, e.g. "कैंसर" or "BP". Don't correct grammar.

Save it as `outputs/asr_reference/<Case>_hi.txt`, with this first line:

```text
# end_ms: 120000
आपका नाम क्या है? उदय सिंह। आपकी उम्र? बत्तीस साल। ...
```

Optional: a faithful English translation of the same 2 minutes, saved as `outputs/asr_reference/<Case>_en.txt` with the same first line. This gives a **chrF** translation score.

## 4. Kajal reference form

Kajal has audio but no reference form, and ManojKumar has a reference form but no audio. That's why only 4 cases are evaluated. Listen to `audio/Kajal.mp3` and create `outputs/ground_truth/Kajal.json` with **exactly the same keys** as `outputs/ground_truth/Uday.json`. Answer from the audio, **not** from the generated form.

## 5. GLiNER neural baseline (Kaggle)

This machine can't install PyTorch, but Kaggle can.

1. Create a **private** Kaggle dataset containing `outputs/ner/*_ner.json` and `baselines/gliner_baseline.py`.
2. In a Kaggle notebook (internet on):
   ```bash
   !pip install gliner
   !python /kaggle/input/<dataset>/gliner_baseline.py --ner-dir /kaggle/input/<dataset> --out-dir /kaggle/working/gliner
   ```
3. Download `/kaggle/working/gliner/*_ner.json` into `outputs/baselines/gliner/` here.
4. Run `python3 src/compare_ner_systems.py`. Once task 2 is done, it scores both systems against your gold annotations.
5. Delete the Kaggle dataset afterwards: it contains patient transcripts.

## 6. Data-privacy decision

Real patient audio, transcripts and forms (55+ files) are **committed to Git**, even though `.gitignore` and the README say they must not be.

- If the GitHub repo is **public**: make it **private** now.
- If it has to stay public for submission, the data must be removed from the **Git history** (not just deleted). Ask before doing this, because it rewrites history for everyone.
- On a slide or in the report, state that the recordings are role-played consultations by consenting classmates, if that's true. Examiners in clinical NLP look for this.
